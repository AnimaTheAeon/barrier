Settings

Kill switch
If the VPN drops, block internet for this container and anything attached to it. Your home network (LAN) keeps working.
Connect automatically
Reconnect to the last location whenever the container starts (for example after a NAS reboot).
Home network ranges
Traffic to these addresses skips the VPN so you can still reach this page and your other devices. The defaults cover almost every home.
Changes apply the next time you connect.
Page password
Your browser asks for it before showing this page (any username works). Leave it empty and save to remove it.

Install updates automatically
Checks for new versions every 6 hours and installs them by itself. Only Barrier's app restarts, for a few seconds; the kill switch stays on the whole time, and it reconnects to the same location afterwards.
